# HNG Anomaly Detection Engine

A DDoS/anomaly detection daemon built for HNG's cloud.ng Nextcloud platform.

## Stack
- Nextcloud (Docker)
- Nginx reverse proxy with JSON logging
- Python detector daemon
- iptables blocking
- Slack alerts
- Live web dashboard
